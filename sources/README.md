- Type: Scientific correspondence.
- Use: Conclusions on genome features and laboratory scenarios.
- Limit: The paper is an argument based on available evidence, not an audit of laboratories.
- Review: Publisher page fetch failed 2026-11-17 (client error). Full text read 2026-11-17 via PubMed Central copy (PMC7095063), which confirms title, authors, Nature Medicine 26(4):450–452, published 17 March 2020, DOI 10.1038/s41591-020-0820-9.
