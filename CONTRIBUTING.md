# Contributing

Contributions should improve factual accuracy, traceability and clarity.

For a proposed factual change, include:

1. The exact claim and repository file.
2. The source URL, publication date and relevant page or passage.
3. What the source establishes and what it does not.
4. Any contrary evidence or relevant response.
5. Whether the change is a documented fact, attributed finding, assessment or proposal.

Use pull requests for edits and the evidence/correction issue template for reports. Keep original files and personal data out of the repository unless publication rights and relevance are clear. Link to public records rather than duplicating large collections.

Do not add private contact details or target individual editors. Focus on institutional decisions and specific, sourced conduct.

Add source metadata to sources/register.json and the annotated index. Update data/claims.csv when a claim changes, and record material corrections in CHANGELOG.md.

For dynamic pages, record the access date and a permanent revision or archive link where available. An unverified archive link should never be described as a verified snapshot.

An external proposal remains a draft until separately submitted. Record any later submission and response accurately.
